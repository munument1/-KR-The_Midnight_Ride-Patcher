# TMR Korean Patcher v1.0.2

## 안전한 플러그인 저장

- 최종 파일을 Mutagen으로 전체 재저장하지 않고 원본 바이너리의 승인된 표시 문자열과 필요한 길이 정보만 바꿉니다.
- 원본 레코드/그룹 헤더, 비표시 필드와 순서를 보존합니다. 대사와 같은 영어가 들어 있는 내부 메모는 번역하지 않습니다.
- PRP의 WRLD OFST·CLSZ 및 연결된 XXXX 제거 정책, UTF-8 번역문, 지몬자 예방적 제외를 유지합니다.
- 정책 버전은 5입니다. 기존 정책 4 이하 payload는 재사용하지 않고 새 백엔드로 번역합니다.
- 검증된 신규 payload 40개와 기존 본편 한국어 리소스·번역 사전을 포함하는 전체 패키지입니다.

## 설치와 기존 사용자

설치법은 기존과 같습니다. 새 ZIP을 별도 폴더에 풀고 패쳐에서 새 Output을 생성한 다음,
Output의 mods/overwrite 내용을 안내된 MO2 경로에 병합합니다. FO4 KOREAN은 MO2에서 직접 활성화합니다.
패쳐는 설치 폴더와 프로필 파일을 변경하거나 프로필 파일을 출력하지 않습니다.

이전 Output으로 ESP/ESM/ESL을 덮어썼다면 해당 플러그인의 공식 원본 또는 적용 전 백업을 복구하고
새 Output을 생성하세요. 이미 변경된 비번역 데이터는 자동 복구되지 않습니다.
사용자 설정·프로필·세이브를 삭제하지 마세요. 모드팩 업데이트 후 이전 Output을 재사용하지 마세요.

외부 문자열 테이블을 사용하는 localized 플러그인은 원본을 유지하고 경고에 표시합니다.
현재 프로필의 Simple Everyone's Best Friend.esp가 해당하며 본편 한국어 Strings는 그대로 제공합니다.
본편 Strings에 없는 모드 고유 문구의 추가 번역을 보장하지는 않습니다.

## 검증 범위

- 자동 테스트 26개 통과.
- 실제 TMR Extended 대상 57개 검사, 40개 출력, 표시 문자열 24,043곳 적용.
- 독립 원시 파서로 95,589개 레코드와 그룹/레코드 헤더, 비표시 데이터, 필드 순서 보존 확인.
- 입력 플러그인 90개와 원본 프로필 파일 14개의 해시 보존 확인.
- PRP 원본 표본 두 파일에서 한글 장소명 및 인덱스 제거 외 모든 하위 필드 보존 확인.
- 게임 내 CTD·지형·프리비즈·성능 검증은 아직 수행하지 않았습니다.
